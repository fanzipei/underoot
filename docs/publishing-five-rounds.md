# Paper → Slides / Poster：五轮迭代记录

用于本次实现和前向验证的材料是仓库内的合成研究论文（`scripts/fixtures/publishing/`），包含研究问题、差距、方法、公式、准确率比较、图片、消融表格、实验条件和局限。数值仅用于软件测试。没有调用真实付费模型，也没有把现有用户论文送到外部服务。

| 轮次 | 检查发现 | 实际修改与复检 |
| --- | --- | --- |
| 1：检查原实现 | 摘要整段进入 `\\small` 正文，靠自动分页；图片集中附在末尾，没有内容层级；仅编译成功不能证明适合演讲或展板 | 定义有来源的论点、方法、证据、边界和可读性标准；保留原稿、全稿分块与完整笔记 |
| 2：内容提纲原型 | 初版重排已关联图注和公式，但真实编译暴露长标题页脚溢出：Slides 11 页、23 条溢出；Poster 意外占 2 页、4 条溢出 | 引入叙事角色、短要点、主张句、来源 ID、图文邻接和原始公式；将问题转入真实 PDF 检查，而不是宣布原型完成 |
| 3：可读性和几何修订 | 页脚长标题需要短显示形式；固定高度栏与 multicol 输出例程产生不希望的分页 | 保留完整标题、缩短页脚显示；海报改为独立连续栏布局，使用可读字号；修正后海报为单页，溢出清零 |
| 4：语义与版面反查 | 公式曾变成 `frac/sum` 的普通文字；转义百分号产生可见反斜杠；重复图注进入要点；按最短栏分配打乱了研究顺序 | 公式原样移植保守安全子集，数字/单位正确转义，图注单独放置；采用连续分组平衡栏位。复检示例为 9 页 Slides、1 页 Poster，无溢出；随后加入表格证据页与同名图路径歧义保护 |
| 5：前向验证与交付检查 | 不能把来源覆盖冒充科学完整性，也不能把编译成功冒充看过每页；独立安装的 skill 不能依赖应用数据库 | 检查全部 16 种模板及中文 Slides/Poster，真实编译并测量页数、文字边界和溢出；增加独立 builder/auditor、结构化提纲、完整讲稿笔记、未解决项和检查状态。保留局限主题，显示层以外的细节单独归档，不伪造主张来源 |

第五轮的逐页视觉反查还发现两处不能只靠编译审计识别的问题：`Research question` 未被识别为问题主题，曾被排到最后；已转成纯文本的百分号再次经过 LaTeX 清理时，被错误地当成注释开头，丢掉了基线和后续限定条件。已区分纯文本与 TeX 输入，并新增完整对照句和研究问题顺序的回归断言；重新生成和审查最终 PDF。

可重复验证：

```bash
npm run test:publishing
EDITORIAL_QA_OUT=<private-qa-directory> npm run test:publishing:quality
```

`test:publishing:quality` 在 XeLaTeX/Poppler 可用时生成 18 份真实 PDF，逐份检查；缺少编译器时明确报告未执行 PDF 检查。报告不会把自动边界检查记成视觉检查。代表样例会渲染为图片供人工检查；发布后的实际论文仍需作者核对科学结论与图像内容。

产品内的五步预检与这里五轮开发迭代是两回事：前者每次生成执行可记录的内容/版面处理，不额外强制五次模型调用。AI 模式负责从分块证据重写叙事，本地模式明确标为结构化草稿。数字原值不匹配、复杂表格/公式、图片歧义或真实编译失败都进入待核对项，不因模板套用完成而隐藏。


## 0.8：先提纲，后生成，继续局部修订

本轮参考了会议官方托管的真实报告与海报，并逐张查看代表页，案例与设计取舍见 [conference-casebook](../skills/underoot-paper-publishing/references/conference-casebook.md)。没有复制研究图像、大学标志或作者结论作为产品模板。

- 第一步显示全稿拆分、样式与调用预算；默认在已配置模型时使用 AI 整理。完成后只持久保存提纲，不创建输出项目。
- 提纲工作台支持编辑标题、结论、要点、原稿插图、布局及顺序，保留来源与未显示细节。预览是布局示意，最终版式以 PDF 为准。
- 确认保存版本后，由不可变源快照及已确认内容生成独立项目；不再次调用全文模型。
- 生成项目中再次选择 Slides / Poster 工具，会打开原来的工作台。对话仅发送选中块、最多三个来源摘要和最近两轮讨论；一次生成一份需接受/拒绝的方案。
- 接受后，只替换稳定标记之间的内容块，保持项目 ID、其他 TeX 字节、素材与历史。TeX 文件发生并发修改、目标块已有手工改动或标记被破坏时拒绝覆盖。
- 生成前提纲、讨论和待确认方案存入 SQLite；生成项目的编辑权限独立校验。原论文删除后，仍可编辑现存的派生项目。

新增图文并列、证据大图、核心主张、双栏对照四种块布局；大图页强调具体发现、证据和条件，结果与结论海报块有视觉强调。侧栏主题根据剩余宽度适配，避免强行使用宽屏比例。

验证包括持久化、权限、过期版本、无额外全文 AI 调用、接受/拒绝、并发保护、表格独立页以及原稿删除后的讨论保留；另有原有生成、共享、模板与核心项目回归。原先 18 份 PDF 检查增加到 22 份，包含新布局。浏览器测试发现的纯表格页无法保存和窄屏导航遮挡问题均已修正。

局限：示意预览不等于 PDF；系统没有宣称运行全套视觉语言模型评分。自动生成仍需要作者检查科学内容、读图语义和打印规格；局部建议应用后应重新编译。此工作台适用于新版生成且带有持久提纲的项目，旧输出项目仍可直接编辑 TeX。


## 0.9：真实高度反馈、模块填满版心、完整署名

- 编译时分别测量每个模块、Slide 正文及海报可用区域的实际高度；先优化连续分栏、字号与图片，再验证模块边框对齐。可在三栏过空时尝试两栏，把最后的结论放到通栏底部。只修改布局参数和呈现，不补造科研结论。
- 海报模块按实测高度分配完整栏高，内部使用段落、项目符号与图文分组的弹性距离；根据实际外框高度再校正一次。自然内容占用率与模块边框覆盖率分开记录。
- 作者与机构按整个版心的中心对齐，两侧图标/二维码采用对称栏位。作者默认 44 pt、单位 34 pt；完整提取多条声明及编号，并提供可编辑字段、图标上传/选择和真实二维码生成。
- 模块默认使用清晰的无衬线正文、1 cm 内边距、轻边框和统一标题分隔线；保留用户显式选择的衬线风格，设置随正文大小变化的项目符号缩进。
- v0.8 已有提纲项目可在原项目中一键重排；先在隔离副本编译，比较当前主文件和生成基线，并在提交前再次检查哈希。手工改动、编译失败、溢出或页数错误会保留原项目。成功后新增重排报告与历史检查点。
- 标准 builder 同步接入实际编译反馈，独立安装 skill 仍不依赖应用数据库。模块对齐可能需要额外一轮验证；后续较差试排会回退并重新编译选中的版式。

验证通过的数据仅来自合成研究样例和隔离服务，没有调用真实收费模型，也没有在生产项目上运行测试。PNG 二维码检查包含目标链接的模块矩阵和白色静区；PDF 检查包含作者居中、大字号、真实页数、边界、溢出、自然内容占用改善与模块框对齐。
